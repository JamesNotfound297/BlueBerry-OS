# BlueBerry OS

> 遵循 Material Design 3 设计风格的浏览器起始页 Chrome 扩展

**版本 0.3.0 — Berry Bliss**

## 功能特性

### 桌面体验
- **MD3 设计风格**：遵循 Material Design 3 设计规范
- **多种壁纸模式**：默认壁纸、流体动态壁纸、纯色壁纸、自定义壁纸（本地文件）、自定义源（URL）、视频壁纸
- **壁纸管理**：下一张/上一张壁纸切换，壁纸模糊（1-5 级）
- **颜色主题**：8 种系统颜色主题（默认/粉/蓝/绿/橙/紫/红/青），影响全局 UI、Logo 文字和系统软件图标

### 自定义组件
- 右键主页 → 自定义组件：拖动搜索栏调整位置、点击图标切换显示/隐藏
- 重置布局功能

### 应用管理
- 系统软件栏：Chrome 设置、书签、历史记录、下载、扩展、实验性功能
- 文件夹管理：创建、重命名、删除文件夹，拖拽快捷方式到文件夹
- 应用卸载：非系统应用支持卸载

### 设置
- **外观**：主题模式（亮色/深色）、颜色主题、流体壁纸、Dock 栏、毛玻璃效果
- **搜索引擎**：必应、Google、百度、维基百科
- **动画**：动画开关、减少动画、动画速度
- **壁纸**：多种壁纸来源、壁纸模糊
- **语言**：简体中文 / English
- **备份与恢复**：导出/导入备份文件（JSON）
- **系统**：恢复系统应用、恢复出厂设置（带警告确认）
- **关于**：版本信息、作者、检查更新

## 安装方式

### 开发者模式加载
1. 下载本项目所有文件
2. 打开 Chrome，访问 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目根目录（包含 `manifest.json` 的文件夹）

## 项目结构

```
chrome-newtab/
├── manifest.json          # 扩展配置
├── newtab.html            # 主页面结构
├── css/
│   └── style.css          # 全部样式
├── js/
│   └── app.js             # 应用逻辑
└── icons/
    └── icon128.svg         # 扩展图标
```

## 技术栈

- Chrome Extension Manifest V3
- Material Design 3
- 原生 JavaScript（无框架依赖）
- CSS 变量主题系统
- Chrome Storage API（设置持久化）
